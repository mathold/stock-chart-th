# My Signal บน MT4 — คู่มือติดตั้งและใช้งาน

ยกชุดอินดิเคเตอร์จากเว็บ (`my_signal.py`) มาลงกราฟ MT4
ต่างจากเว็บตรงที่ **MT4 ได้ราคาเรียลไทม์จากโบรกเกอร์** ไม่ดีเลย์ 15-20 นาทีแบบ Yahoo
จึงใช้ตัดสินใจเข้า-ออกจริงได้ (เว็บใช้ดูภาพรวมอย่างเดียว)

---

## 1. ไฟล์ในโฟลเดอร์ MT4 นี้

| ไฟล์ | ชนิด | วางที่ | ทำอะไร |
|---|---|---|---|
| `MySignal.mq4` | Indicator | `MQL4/Indicators` | ริบบิ้น BBE 13/34 + ลูกศรซื้อ/ขาย + เลข 1-9 + กล่องสถานะ + แจ้งเตือน |
| `MySignal_DE.mq4` | Indicator | `MQL4/Indicators` | DE เงินไหลเข้า/ออก (หน้าต่างล่าง) |
| `MySignal_MCD.mq4` | Indicator | `MQL4/Indicators` | MCD กระจายต้นทุน 100% + เส้น MA10 (หน้าต่างล่าง) |
| `MySignal_EA.mq4` | EA | `MQL4/Experts` | เทรดอัตโนมัติตามกฎ My Signal |
| `RibbonBS.mq4` | Indicator | `MQL4/Indicators` | ริบบิ้น EMA 25/75 + ป้าย B/S (ของเดิม) |
| `RibbonBS_Alert.mq4` | Indicator | `MQL4/Indicators` | ตัวเดิม + แจ้งเตือน |
| `RibbonBS_EA.mq4` | EA | `MQL4/Experts` | EA ตัดเส้น 25/75 (ของเดิม) |

**ลง `MySignal.mq4` ตัวเดียวก็ใช้ได้ครบ** — DE คำนวณอยู่ข้างในแล้ว
สองไฟล์ DE/MCD มีไว้ให้ *เห็น* เป็นแท่งข้างล่างเหมือนบนเว็บเท่านั้น

---

## 2. ติดตั้ง (ทำครั้งเดียว)

1. เปิด MT4 → **File > Open Data Folder** → เข้าโฟลเดอร์ `MQL4`
2. ก๊อป 3 ไฟล์ `MySignal*.mq4` ที่เป็น Indicator ลง `MQL4/Indicators`
   และ `MySignal_EA.mq4` ลง `MQL4/Experts`
3. กลับมา MT4 → กด **F4** เปิด MetaEditor → เปิดไฟล์ทีละตัว → กด **F7** คอมไพล์
   (ต้องขึ้น `0 errors` ถ้ามี error ให้ก๊อปข้อความมาบอกได้)
4. กลับมา MT4 → หน้าต่าง **Navigator** คลิกขวา → **Refresh**
5. ลากชื่ออินดิเคเตอร์จาก Navigator ใส่กราฟ

> เครื่อง Mac ที่รัน MT4 ผ่าน Wine/PlayOnMac ก็ทางเดียวกัน แค่หา Data Folder
> ผ่านเมนู File > Open Data Folder เหมือนกัน อย่าไปเดาพาธเอง

## 3. ตั้ง 4 จอเหมือนบนเว็บ

MT4 ไม่มีโหมด 4 ไทม์เฟรมในหน้าต่างเดียว แต่ทำได้ด้วย Template + Profile:

1. เปิดกราฟสินค้าเดียวกัน **4 หน้าต่าง** (เมนู File > New Chart 4 ครั้ง)
2. ตั้งไทม์เฟรมทีละจอ เช่น **M30 · H1 · H4 · D1**
   (ของเว็บคือ intraday/Day/Week/Month — บน MT4 ที่เทรดสั้นกว่าควรเลื่อนลงมา)
3. ลง `MySignal` (+ `MySignal_DE`, `MySignal_MCD` ถ้าต้องการ) ให้ครบทุกจอ
4. คลิกขวาบนกราฟ → **Template > Save Template** ตั้งชื่อ `mysignal`
   จอที่เหลือคลิกขวา → **Template > Load Template > mysignal** จะได้เหมือนกันทันที
5. เมนู **Window > Tile Windows** (หรือ Alt+R) จัดเป็น 4 ช่อง
6. เมนู **File > Profiles > Save As** ตั้งชื่อ `4TF`

**เปลี่ยนสินค้าทั้ง 4 จอทีเดียว:** ลากชื่อสินค้าจาก Market Watch มาวางบนกราฟทีละจอ
(MT4 ไม่มีปุ่มเปลี่ยนทุกจอพร้อมกัน) หรือทำ Profile แยกไว้ต่อสินค้า เช่น
`4TF-XAU`, `4TF-EUR` แล้วสลับด้วย File > Profiles ซึ่งเร็วกว่าตั้งใหม่ทุกครั้ง

**ทำ Template ให้ครบชุด** ตั้งค่าสี/พื้นหลังดำให้เหมือนเว็บก่อนเซฟ:
คลิกขวา > Properties > Colors > เลือก Black on White แล้วปรับ Background เป็นดำ

## 4. อ่านกราฟยังไง (กฎเดียวกับบนเว็บ)

| เห็นอะไร | แปลว่า |
|---|---|
| ริบบิ้นเขียว | ขาขึ้น — ถือของได้ |
| ริบบิ้นแดง | ขาลง — ถือเงินสด |
| ลูกศรเหลือง ▲ ใต้แท่ง | **สัญญาณซื้อ** (ริบบิ้นพลิกเขียว หรือ DE ตัดขึ้นเหนือ 0) |
| ลูกศรแดง ▼ เหนือแท่ง | **สัญญาณขาย** (ริบบิ้นพลิกแดง หรือ DE ตัดลงใต้ 0) |
| จุดเขียวใต้แท่ง | ถือของต่อ ไม่ต้องทำอะไร |
| จุดชมพูใต้แท่ง | ถือเงินสด ไม่ต้องทำอะไร |
| เลขฟ้าเหนือแท่ง | นับขึ้น 1-9 — **ไม่ใช่สัญญาณขาย** ใช้คุมขนาดไม้ |
| เลขส้มใต้แท่ง | นับลง 1-9 |
| กล่องมุมจอ | สรุปว่าตอนนี้ควรทำอะไร |

**กล่องสถานะ** ไล่จากเด็ดขาดที่สุดลงมา: `ออก` → `อยู่เฉย` → `ซื้อเต็มไม้` →
`ซื้อครึ่งไม้` → `ลดไม้` → `ถือต่อ` ตรรกะตรงกับ `status()` ในไฟล์เว็บเป๊ะ

**เลข 9 ไม่ใช่จุดขาย** เทรนด์แรง ๆ นับ 1-9 วนได้หลายรอบ
ขายจริงรอริบบิ้นพลิกแดง หรือลูกศรแดงเท่านั้น

## 5. แจ้งเตือนเข้ามือถือ

1. ลงแอป **MetaTrader 4** บนมือถือ → เมนู Settings > Messages → ก๊อป **MetaQuotes ID**
2. MT4 บนคอม → **Tools > Options > Notifications** → ติ๊ก Enable Push Notifications
   ใส่ MetaQuotes ID → กด Test ต้องเด้งเข้ามือถือ
3. บนกราฟ ดับเบิลคลิกอินดิเคเตอร์ `MySignal` → แท็บ Inputs → ตั้ง `AlertPush = true`

ค่าเริ่มต้น `StatusOnClosedBar = true` คือ **เตือนเมื่อแท่งปิดแล้วเท่านั้น**
อย่าไปปิด ไม่งั้นจะโดนสัญญาณหลอกตอนแท่งยังวิ่งอยู่เตือนกลับไปกลับมา

> คอมต้องเปิด MT4 ค้างไว้ถึงจะเตือน — MT4 ไม่มีเซิร์ฟเวอร์เตือนแทนให้

## 6. EA — ขั้นตอนที่ควรทำก่อนใช้เงินจริง

**อย่าเพิ่งเปิดใช้กับบัญชีจริง** ไล่ตามนี้:

### 6.1 Backtest
1. **View > Strategy Tester** (Ctrl+R) → เลือก `MySignal_EA`
2. Symbol = สินค้าที่จะเทรด · Period = ไทม์เฟรมที่จะรัน (แนะนำเริ่มที่ H1 หรือ H4)
3. Model = **Every tick** (ช้าแต่ตรงที่สุด) · ช่วงเวลาอย่างน้อย 2-3 ปี
4. กด Start → ดูแท็บ **Report**: Profit Factor, Max Drawdown, จำนวนไม้

ตัวเลขที่ควรดูก่อน: **จำนวนไม้ต้องเกิน 100** ไม่งั้นผลที่ได้เป็นความบังเอิญ
และ **Max Drawdown** ต้องรับได้จริงในใจ ไม่ใช่แค่บนกระดาษ

### 6.2 เปิดตัวกรองทีละตัว
ค่าเริ่มต้นปิดตัวกรองไว้หมด = ได้กฎ My Signal ล้วน ๆ เป็นเส้นฐานไว้เทียบ
แล้วค่อยเปิดทีละตัว รันใหม่ จดผลเทียบกัน:

| อินพุต | ลองเปิดเมื่อ |
|---|---|
| `RequireDeAbove0` | สัญญาณเยอะเกิน อยากเอาเฉพาะที่เงินเข้าแล้วจริง |
| `SkipWhenCount9` | ชอบเข้าไม้ตอนปลายเทรนด์แล้วโดนย่อ |
| `ReduceOnFade` | อยากล็อกกำไรครึ่งหนึ่งตอนแรงเริ่มหมด |
| `UseTrendFilter` | ขาดทุนเยอะจากไม้สวนเทรนด์ใหญ่ |
| `UseAdxFilter` / `UseRibbonGapFilter` | เสียเยอะช่วงไซด์เวย์ |
| `UseTrailing` / `UseBreakEven` | ไม้กำไรกลับมาขาดทุนบ่อย |

`HalfLotUnconfirmed` เปิดไว้ตั้งแต่ต้น = แปลงคำว่า "ซื้อครึ่งไม้" บนเว็บ
มาเป็นขนาดไม้จริง ๆ (เข้าครึ่งขนาดเมื่อ DE ยังไม่ยืนยัน)

### 6.3 Optimization
ติ๊ก Optimization ใน Strategy Tester แล้วไล่ค่า `BbeFast` / `BbeSlow` / `SlAtrMultiple`
**อย่าเลือกชุดที่กำไรสูงสุดชุดเดียว** — ให้เลือกชุดที่ค่ารอบ ๆ ก็ยังกำไร
(กำไรสูงโดดเดี่ยว = fit กับอดีต พอเจอของจริงจะพัง)

### 6.4 เดโมอย่างน้อย 1 เดือน
รันบัญชีเดโมด้วยค่าที่เลือก ดูว่าผลใกล้เคียง backtest ไหม
ถ้าต่างมาก แปลว่าสเปรด/สลิปเพจของโบรกกินไปหมด ต้องกลับไปปรับ

### 6.5 เงินจริง
เริ่มที่ `RiskPercent = 0.5` ก่อน ไม่ใช่ 1.0 และรันสินค้าเดียวก่อน

## 7. ข้อจำกัดที่ต้องรู้

- **วอลุ่มใน MT4 เป็น tick volume** (จำนวนครั้งที่ราคาขยับ) ไม่ใช่ปริมาณซื้อขายจริง
  → **DE และ MCD จึงไม่ตรงกับตัวเลขบนเว็บ** ใช้ดูแนวโน้มได้ แต่อย่าเทียบเลขตรง ๆ
- **MCD ยิ่งห่างจากของจริง** — Homily แยกรายใหญ่/รายย่อยจากขนาดคำสั่งซื้อขายรายไม้
  MT4 ไม่มีข้อมูลนั้น ไฟล์นี้แยก "กำไร/ลอย/ติดดอย" จากราคาทุนแทน
- **`MySignal_MCD` กินซีพียู** ถ้ากราฟอืดให้ลด `McdBars` จาก 600 เหลือ 300
- **หุ้นไทยไม่มีใน MT4** โบรกให้แค่ forex, ทอง, น้ำมัน, ดัชนี CFD, คริปโต CFD
  ดูหุ้นไทยต่อที่เว็บ https://mathold-stock.streamlit.app
- **สูตรจริงของ Homily เป็นความลับ** ทั้งเว็บและไฟล์ MT4 ชุดนี้ทำเลียนแบบจากพฤติกรรม
  ที่เห็นในคู่มือ + ภาพตัวอย่างเท่านั้น ตัวเลขไม่ตรงกับโปรแกรมจริง
- ทุกอย่างในโฟลเดอร์นี้เป็นเครื่องมือประกอบการตัดสินใจ **ไม่ใช่คำแนะนำการลงทุน**
  ผลในอดีตไม่รับประกันอนาคต
